Communication Tiles: Setup and Use

This activity is available in two versions with the same communication model: tactile/communication-tiles/ and eyegaze/communication-tiles/.

Included content model

  • Basic set: eat, drink, bathroom, break, more, stop, help, pain, happy, sad.
  • Expanded set: adds hot, cold, yes, no, finished, and music.
  • Sentence strip: combines starter + selected words, for example: I want + drink.

Configuration options

  • Vocabulary set: switch between basic and expanded.
  • Spoken feedback: use TTS, pre-recorded audio (if tile audio URLs are provided), or none.
  • Confirmation mode: click confirmation or dwell confirmation.
  • Dwell duration: tune dwell delay from 400ms to 3000ms.
  • Sentence starter: choose from “I want”, “I need”, and “I feel”.

Editing vocabulary

Edit shared vocabulary in js/communication-tiles-data.js. Both tactile and eye-gaze pages use this same file. To add pre-recorded audio, add an audio URL on any item object.
